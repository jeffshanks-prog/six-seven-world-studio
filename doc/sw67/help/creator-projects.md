# Creator Project Manager

Open **Me > 6|7 Studio > Creator Projects...**

A project is a folder you choose. A plain JSON file, `project.sw67.json`,
sits beside your files and lists them.

1. Choose or create a folder.
2. **Scan folder** adds mesh sources, textures, scripts, references and
   exports, sorted by file type.
3. Keep revision history, testing notes and the release checklist (nine
   default items) up to date.
4. The readiness report lists missing files, unticked checklist items and
   scripts without testing notes.

**Remove from project** never deletes a file. Projects stay readable without
the viewer or a subscription. Linking inventory items from the window is
PLANNED.

Status: AVAILABLE in development builds; not yet tested in a released build.
