# Accessibility

Open **Me > 6|7 Studio > Accessibility...**

- **Interface palette**: presets for common colour vision types (for example
  Deuteranopia). Status messages always use a symbol and a word as well as a
  colour.
- **Text size**: scales interface text.
- **Scene colour filter**: applies the renderer's colour vision filter to the
  world. You choose whether it also applies to snapshots.
- Accessibility settings are never changed by Workspace Profiles or imported
  files, and are never gated by a subscription.

Status: AVAILABLE in development builds; not yet tested in a released build.
