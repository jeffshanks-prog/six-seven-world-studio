# Animation overriders

- The viewer has a built-in animation overrider from Alchemy. Open it with
  the **AO** toolbar button (add it from the toolbar buttons window if it is
  not shown). It replaces standing, walking, sitting and other default
  animations with ones from your inventory.
- Scripted AO HUDs from other creators also work as in any viewer.
- **AO Builder**, a guided tool for building AO sets, is PLANNED.
