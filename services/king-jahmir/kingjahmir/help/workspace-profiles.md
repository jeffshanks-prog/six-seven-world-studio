# Workspace Profiles

Open **Me > 6|7 Studio > Workspace Profiles...**

A profile is a screen layout: which windows are open and where, toolbar
buttons and keyboard shortcuts. Built-in profiles: **Everyday**, **Creator**,
**Photographer**, **DJ** and **Host**. You can save your own.

1. Pick a profile in the list.
2. Click **Preview** to see every window it would open, move or close and
   every toolbar, shortcut or preference change. Nothing changes yet.
3. Click **Apply**. To go back, click **Undo apply**.
4. To keep your current layout, click **Save the current layout** and name it.
5. **Export** writes a profile to a file; **Import** reads one, checks it, and
   changes nothing until you apply it.

Accessibility settings, the RLV on/off switch and anything that looks like a
password or key are never saved in or applied from a profile. Toolbars are
per account, so you must be logged in to save or apply them.

Status: AVAILABLE in development builds; not yet tested in a released build.
